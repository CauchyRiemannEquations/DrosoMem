# Flying: 연결망 기반 순서 학습·기억 연구

이 저장소는 초파리 뇌 연결 구조를 활용한 계산 모델의 학습, 기억, 자율 회상을
연구한다. 원주율은 순서 기억을 측정하는 통제된 과제다. 모델·실험·분석·재현성과
과학적 보고를 이 저장소의 범위로 삼는다.

## 핵심 질문

1. 실제 연결 구조가 무작위화한 대조 구조보다 순서 기억에 유리한가?
2. 입력 범위, 연결 임계값, 시간 동역학과 출력층 학습이 회상에 어떻게 기여하는가?
3. 연결 구조를 보존하는 가중치 학습이 고정 연결망 기준 모델을 개선하는가?
4. 부분망의 결과가 전체 뇌 규모에서도 유지되는가?

## 현재 근거

- 고정 연결망과 학습된 출력층을 사용하는 rate 기준 모델이 있다.
- 강건성, 커리큘럼 확인, 소규모 LIF와 국소 도파민 실험에는 실패·부정 결과가 있다.
  구현 완료와 가설 성공을 구별한다.
- Phase 6는 원본 138,639개 뉴런·15,091,983개 연결의 실행과 반복 재현을 확인했다.
  약한 연결 복원 후 MBON11 기본 반응이 회복됐지만, 전체 뇌의 원주율 학습·회상
  성능이나 도파민 학습 효과를 검증한 것은 아니다.

## ACT I 결과와 다음 연구

2026-09-28 ACT I은 같은 입력 ID·48 MBON·482개 출력층 파라미터로 50회를
비교했다. 평균 회상은 부분망 35.0, 전체 threshold5 31.8, threshold1 34.1로
전체망 우위 기준을 통과하지 못했다. [설계](whole-brain-memory-protocol.md)와
[결과](whole-brain-memory-results.md)에 모든 seed와 표현 진단을 보존한다.

ACT II의 π·무작위 숫자·섞은 π·주기 수열 pilot도 80회 비교를 완료했다.
두 모델 모두 제한적 beyond-π 기준을 통과했지만 whole-brain 우위는 확인되지
않았다. 주기 수열은 단순 전이 대조 모델도 완주했다. [결과](sequence-memory-results.md).
다음은 무작위 수열의 길이별 회상 scaling 실험이다. ACT I→II→III→IV 순서를
지키며 도파민 가소성 확장을 앞당기지 않는다. 강건성은 ACT V의 독립 축이다.
[로드맵](research-roadmap.md).

## 증거와 재현성

정답 수열은 학습·평가 단계에서만 사용하며, 자율 회상은 생성한 숫자를 다음
입력으로 사용한다. 학습 정확도, 첫 오류 전 연속 회상, 구간별 정확도를 구분한다.
모든 사전 지정 seed와 대조군을 보고하고 실패한 결과도 보존한다.

현재 문서는 연구 범위에 맞춰 용어를 정리했다. 과거 연구의 수치, 저장 가중치,
manifest와 체크섬은 변경하지 않는다. 당시 소스와 프로토콜의 정확한 바이트를
검사하는 재현은 기록된 Git revision에서 수행한다. 자세한 절차는
[과거 결과 재현](historical-reproduction.md)을 따른다.
