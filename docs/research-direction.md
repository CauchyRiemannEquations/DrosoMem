# Flying: 연결망 기반 순서 학습·기억 연구

이 저장소는 초파리 뇌 연결 구조를 활용한 계산 모델의 학습, 기억, 자율 회상을
연구한다. 원주율은 순서 기억을 측정하는 통제된 과제다. 모델·실험·분석·재현성과
과학적 보고를 이 저장소의 범위로 삼는다.

## 핵심 질문

1. 실제 연결 구조가 무작위화한 대조 구조보다 순서 기억에 유리한가?
2. 입력 범위, 연결 임계값, 시간 동역학과 출력층 학습이 회상에 어떻게 기여하는가?
3. 연결 구조를 보존하는 가중치 학습이 고정 연결망 기준 모델을 개선하는가?
4. 부분망의 결과가 전체 뇌 규모에서도 유지되는가?

## 현재 근거

- 고정 연결망과 학습된 출력층을 사용하는 rate 기준 모델이 있다.
- 강건성, 커리큘럼 확인, 소규모 LIF와 국소 도파민 실험에는 실패·부정 결과가 있다.
  구현 완료와 가설 성공을 구별한다.
- Phase 6는 원본 138,639개 뉴런·15,091,983개 연결의 실행과 반복 재현을 확인했다.
  약한 연결 복원 후 MBON11 기본 반응이 회복됐지만, 전체 뇌의 원주율 학습·회상
  성능이나 도파민 학습 효과를 검증한 것은 아니다.

## ACT I 결과와 다음 연구

2026-09-28 ACT I은 같은 입력 ID·48 MBON·482개 출력층 파라미터로 50회를
비교했다. 평균 회상은 부분망 35.0, 전체 threshold5 31.8, threshold1 34.1로
전체망 우위 기준을 통과하지 못했다. [설계](whole-brain-memory-protocol.md)와
[결과](whole-brain-memory-results.md)에 모든 seed와 표현 진단을 보존한다.

ACT II의 π·무작위 숫자·섞은 π·주기 수열 pilot도 80회 비교를 완료했다.
두 모델 모두 제한적 beyond-π 기준을 통과했지만 whole-brain 우위는 확인되지
않았다. 주기 수열은 단순 전이 대조 모델도 완주했다. [결과](sequence-memory-results.md).
무작위 수열의 길이32–512 scaling도100회 실행·재현했다. 길이512의 평균 연속
회상은 부분망14.6·전체망9.5이며, 고정 학습 절차에서 전체망 우위가 확인되지
않았다. [결과](length-scaling-results.md). 길이512에서 초반 target의 학습 비중만
바꾼 후속 실험도 완료했다. 새 seed에서 초반 회상 증가는 재현됐지만, 두 모델
모두 후반 정답 입력 정확도의 허용 손실 범위를 넘었다. 고정된 신경 상태에서
출력층의 학습 우선순위가 만든 상충 관계다. [결과](prefix-mass-results.md).
독립 무작위 입력의 과거 기호 해독도20개 조건과 전체 반복 검증을 완료했다.
같은48 MBON에서 평균 과거 지연 정답률은 부분망60.42%·전체망51.10%이며,
전체망 우위 기준은 통과하지 못했다. [결과](delayed-symbol-results.md).
길이128의 K=2·4·10·16 비교도80회 실행·재현했다. 두 모델 모두 각K의 제한적
trained-prefix 기준을 통과했지만 전체망 우위는 확인되지 않았다. K2→K16에서
평균 회상은 부분망25.0→103.1, 전체망27.3→88.0으로 늘었다. 이 증가를 정보
저장 용량 증가로 해석하지 않는다. [결과](alphabet-memory-results.md).
기존80개 실행에 포함된20개 수열의 [문맥 대조 분석](context-memory-results.md)도
완료했다. 120개 문맥 모델을 독립 검증했으며, K2→K16에서 문맥 충돌 감소와
고정3기호 문맥 회상 증가의 사전 기준을 모두 통과했다. 신경망 내부의 인과적
원인을 확인한 것은 아니다. [고정K 문맥 개입](context-intervention-results.md)도 완료했다.
본 실험40회와 확인24회에서 사전 기준을 충족한 개선 모델은 없었다.
후속 [저장 상태 해독](frozen-state-probe-results.md)과 [고정 출력층 교차 전이](cross-arm-probe-results.md)도 완료했다.
과거 기호 접근성과 제한적 전이는 지지됐으나 다음 기호 개선은 확인하지 못했다.
후속 [현행 K4 구조 대조](structural-k4-results.md)도 완료했다. 독립 수열의 과거
해독은 실제 76.965% / 재배선 78.603%로 실제 배선 우위를 확인하지 못했다.
후속 [정규화 계수 대조](normalization-control-results.md)는 본30회·확인18회를 마쳤다.
계수 고정의 이득은1.245%p/0.894%p로 사전 확인 기준1%p에 못 미쳤다.
후속 [고정 출력층 전이](normalization-transfer-results.md)는 양방향·두 집단 모두
실패했다. Target refit 약79–80%와 frozen 전이25–27%를 구분한다.
후속 [학습 상태 평균·표준편차 정렬](moment-alignment-results.md)은 전이를49–53%로
개선했지만 R² 및5%p 유지 기준에 실패했다. Head는 고정, 전처리만 적응했다.
후속 [source-mode 분해와 에너지 보존 방향 대조](residual-orientation-results.md)도
완료했다. 저분산 하위 절반 지배와 특별한 readout-sensitive 방향 증폭 가설은
모두 실패했다. 후속 [새 seed 정렬 확인](fresh-alignment-results.md)은 양방향 개선을
재현했지만 접근성·유지 기준은 실패했다. 후속 [KCγ 제거 및 비중복 대조](kc-ablation-results.md)는
두 refit 비교 모두 집단 특이적 손상 기준을 통과하지 못했다. 후속 [고정 출력층 비교](kc-frozen-results.md)는
큰 재학습 이득을 확인했지만 고정 전이·KCγ 특이성은 실패했다. 후속 [새 seed 확인](kc-confirmation-results.md)은
재학습 이득을 재현했다. 다음 한 제안은 직접 입력만 차단하고 recurrent 연결을
남긴 대조를 전체 뉴런 제거와 비교해 추가 연결 제거의 효과를 구분하는 것이다.
추가 gain 탐색이나 ACT IV 확장은 하지 않는다.
ACT I→II→III→IV 순서를 지키며 강건성은 ACT V의 독립 축으로 유지한다.

## 증거와 재현성

정답 수열은 학습·평가 단계에서만 사용하며, 자율 회상은 생성한 숫자를 다음
입력으로 사용한다. 학습 정확도, 첫 오류 전 연속 회상, 구간별 정확도를 구분한다.
모든 사전 지정 seed와 대조군을 보고하고 실패한 결과도 보존한다.

현재 문서는 연구 범위에 맞춰 용어를 정리했다. 과거 연구의 수치, 저장 가중치,
manifest와 체크섬은 변경하지 않는다. 당시 소스와 프로토콜의 정확한 바이트를
검사하는 재현은 기록된 Git revision에서 수행한다. 자세한 절차는
[과거 결과 재현](historical-reproduction.md)을 따른다.
