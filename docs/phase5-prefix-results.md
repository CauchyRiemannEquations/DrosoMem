# 초반 가중 학습: 연속 회상 개선과 후반 정확도 감소

**실제 연결의 평균 연속 회상은 9.93→32.43자리로 늘었다. 10개 paired 조건 모두 초기화 평균이 개선됐고 9개는 세 초기화 모두 개선됐다. 하지만 후반 정확도는 86.69%→78.77%로 감소했다. 출력층의 학습 비중 조정에 따른 접두사 회상 개선이며, 전체 기억 용량 증가나 연결 학습의 성공은 아니다.**

## 실험

이전 비선형 출력층 연구의 제안대로 incoming-L1 + mbon_after_kc를 고정했다. 두 686뉴런 부분망, 새로운 seed 1042–1046, 실제/role-degree-shuffled 연결, 세 출력층 초기화, 균등/초반 가중 학습으로 **120개 모델**을 학습했다. 20개 고정 신경 상태 조건에 대한 paired 비교이며 120개의 독립 생물학 표본이 아니다.

두 처리 모두 동일한 48 MBON 상태, 비가중 학습 평균·표준편차, 동일 초기화, 482개 출력층 파라미터, Adam 2,000회, 학습률 .03, L2=1e-5를 썼다. 의도된 처리 차이는 loss 가중치다. `314` 다음 처음 32개 target, digit index 3–34의 cross entropy에 4배 가중치를 주고 나머지는 1배로 두었다. 가중치 합으로 정규화하고 L2는 유지한다. 입력/재귀 연결은 학습하지 않았다. 생성에는 시간 위치·정답·새로운 외부 기억을 제공하지 않는다.

200자리 학습열에서 `314`를 한 번 제공하고 197자리 생성한다. 점수는 **제공한 세 숫자를 제외한, 첫 오류까지 연속으로 맞힌 새 숫자 수**다.

## 측정 결과

| 연결 | 균등 학습 | 초반 4배 가중 | paired 평균 차이 | 조건별 승/무/패 | 모든 초기화에서 개선 |
|---|---:|---:|---:|---:|---:|
| 실제 | 9.93 | 32.43 | +22.50 | 10 / 0 / 0 | 9 / 10 |
| 역할별 연결 섞기 | 10.67 | 34.00 | +23.33 | 9 / 0 / 1 | 8 / 10 |

각 조건 안에서 세 초기화를 평균한 뒤 열 개 조건을 비교했다. 실제 연결의 개별 모델 중앙값은 6.5→33.5자리, 처음 32자리를 모두 맞힌 모델은 **1/30→25/30**이었다. 초반 가중 모델의 실제 연결 범위는 7–43자리로 완주 보장은 아니다. 최고점 43을 대표 용량으로 쓰지 않는다. 197자리 전체 완주는 없었다.

| 실제 연결 분류 지표 | 균등 학습 | 초반 가중 |
|---|---:|---:|
| 초반 32자리 정확도 | 86.77% | 99.48% |
| 이후 165자리 정확도 | 86.69% | 78.77% |
| 전체 199개 학습 target 정확도 | 86.77% | 82.06% |
| 비가중 cross entropy | 0.4058 | 0.5710 |

대조군도 초반 정확도 91.15%→99.58%, 후반 90.79%→82.97%로 같은 방향이었다. `training.csv`의 objective/cross_entropy는 처리별 **가중 학습 목적함수**다. 처리 간 공통 기준은 `evaluations.csv`의 **비가중** cross_entropy다. 전체 정확도에는 prompt 내부의 두 target도 포함되지만 초반/후반 지표에서는 제외된다.

## 해석

이번 구성에서는 **π를 처음부터 더 길게 이어 쓰게 하는 데 성공했다.** 동시에 더 뒷부분의 정답률과 전체 평균 적합은 나빠졌다. 같은 신경 상태와 같은 출력층이 학습 비중을 바꾸면서 오류를 뒤로 옮길 수 있다는 결과다. 새로운 연결 기억이나 총 정보량 증가의 증거는 아니다.

120개 모두 자유 회상의 첫 오류와 참 입력 경로의 첫 분류 오류가 일치했다. 첫 오답이 자기 입력으로 돌아오기 이전의 오류를 줄인 결과다. 연결을 섞어도 비슷하게 개선됐으므로 실제 초파리 배선만의 우위도 입증하지 않는다.

이전 보고서의 전체 평균 5.75자리와 이번 32.43자리를 직접 paired 비교하면 안 된다. 이번에는 선택한 정규화/스케줄과 새 seed를 사용했다. 유효한 비교는 이번 동일 조건 균등 학습 **9.93자리**다. 두 부분망은 같은 개체에서 왔고 겹친다. 시드는 생물학적 반복이 아니다. 개체군 통계적 유의성, 정보이론적 한계, 미학습 π 예측을 주장하지 않는다.

## 검증

- 전체 pytest **65개 통과**. 가중 기울기 유한차분, 균등·가중치 배율 동등성, 잘못된 가중치, target 인덱스, 학습 통계 유지 검사를 포함한다.
- **20개 상태 재구축, 120개 저장 출력층의 전체 회상 문자열 정확히 재생**.
- 실제 첫 부분망·첫 seed의 두 목적함수 × 세 초기화인 **6개 모델을 독립 재학습**해 파라미터 해시까지 일치. 나머지 114개는 저장 모델 재생이며 전체 재학습을 주장하지 않는다.
- 원자료/소스/설계/산출물 해시, 고정 연결, 훈련 통계, 위치별 예측, first-error 일치를 검증했다.
- 학습 약 **190초**, Python 3.12.14. 패키지는 manifest에 기록했다.
- 과거 Work의 pytest/mpmath 부재는 이번에 해결됐다. 로컬 복원 중 추가 개행을 원본 Git blob SHA에 맞게 수정했고 데이터 해시 통과 후 최종 실행했다.

## 다음 판단

Whole-brain은 계속 보류한다. 다음으로 **32자리/4배 규칙을 변경하지 않고** 새 seed와 별도의 π 학습 구간에서 독립 확인하는 것이 우선이다. 구간을 결과를 보기 전에 고정하고 각 구간의 첫 세 숫자만 prompt로 준다. 첫 구간에만 유리한 규칙인지, 일반적인 접두사 우선 학습 효과인지와 후반 정확도 손실을 확인한다. 이 후속 확인은 이번에 실행하지 않았다. 여러 가중 구간을 시도해 최고값만 고르거나 이 결과만으로 전체 뇌를 늘리는 것은 근거를 넘는다.
