# Flying: 사람 대 초파리 연결망 모델의 원주율 암기 대결

## 최종 목표

플레이어가 **초파리 두뇌 구조를 활용해 학습한 계산 모델**과 원주율 암기를
겨루는 게임을 만든다. 현재 연구는 게임 상대의 학습 방식, 회상 길이, 안정성,
난이도와 재현성을 검증하는 과정이다. 사용자와 이 의도를 2026-09-27에 확인했다.

현재 강한 기준 모델은 FlyWire 부분망의 recurrent 연결을 고정하고 출력층을
학습한다. 장기적으로 구조를 보존하는 연결 가중치 학습도 연구하되, 화면과
보고서에는 실제로 학습한 부분을 정확히 설명한다.

## 첫 게임으로 연결할 기준

- 같은 시작 prompt `314`와 같은 첫 오류 규칙으로 사람과 모델을 채점한다.
  제공된 세 숫자는 점수에서 제외한다. 두 참가자의 연속 정답 수가 같으면 무승부다.
- 모델은 검증된 저장 가중치로 한 자리씩 자율 생성한다. 정답 π는 별도의
  채점기에만 둔다. 정답 조회나 사후 생성열 교체로 상대 실력을 꾸미지 않는다.
- 첫 프로토타입은 이미 검증된 고정 32자리 가중 모델을 상대 후보로 사용할 수
  있다. 전체 뇌나 128자리 완주가 게임 제작의 필수 선행조건은 아니다.
- 모델 선택·난이도는 플레이 전에 정하고, 측정된 회상 분포와 조건을 기록한다.
  최고 seed만 골라 일반적인 성능처럼 제시하지 않는다.
- 우선 로컬 게임 로직과 저장 모델 내보내기를 검증하고, 이후 플레이 가능한 UI,
  학습 시각화, 사람/모델 차례와 점수 표시를 추가한다.

## 현재 작업과 다음 단계

1. 완료: 기존 연구 결과를 main에 병합, Windows 재현 오류 수정.
2. 완료: 초반 32자리의 손실 비중을 유지하는 범위 확장 탐색. 기본 시작 구간에서
   평균 회상 31.67→38.89자리, 초반 유지 기준 통과. 후반 정확도 비용이 있어
   다른 구간의 별도 확인 전에는 기본 모델로 승격하지 않는다. [결과](phase5-retention-results.md).
3. 완료: 고정 32자리 가중 모델 18개의 상대 어댑터, 공통 채점기,
   기본 10분 준비 시간과 콘솔 게임. 모두 197자리 출력을 재현했다.
   [실행법과 검증](game-prototype.md).
4. 다음 제품 작업: 준비 → 회상 → 결과를 연결하는 첫 그래픽 UI.
5. 이후: 준비 시작과 함께 실제 새 출력층을 학습시키는 모드. 현재 규모의
   6,000회 학습은 이 PC에서 준비 포함 약 2.62초였다. 10분 내내 학습하면
   회상이 더 좋아지는지는 별도 실험 대상이다.

## 10분 암기 준비 구상

사용자가 제안한 10분을 초기 기본값으로 둔다. 현재 상대는 학습된 가중치로
실행하며 사전 학습 모델임을 밝힌다. 정답열을 내장해 재생하지 않는다.
실제 동시 학습 모드는 학습 횟수와 진행률을 표시하고 완료된 모델을 대결 전에
고정한다. 학습이 일찍 끝났는데 10분 내내 학습하는 듯한 연출을 하지 않는다.
사람에게 적절한 준비 시간과 난이도는 플레이테스트로 조정한다.

## 작업 방식

검증된 변경과 연구 결과는 **main에 직접 커밋·푸시**한다. 일반적인 작업마다
PR 생성이나 병합 확인을 다시 요청하지 않는다. 실패한 실험도 정직하게 기록하되,
효과가 확인되지 않은 방식을 게임의 기본 상대 학습법으로 승격하지 않는다.
