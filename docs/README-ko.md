# Flying: 실제 연결 구조를 사용한 계산 모델의 순서 기억 연구

Flying은 **실제 초파리 connectome 구조를 사용한 계산 모델**이 입력의 순서를
어떻게 보존하는지 연구합니다. 살아 있는 초파리에게 원주율을 가르친 실험이
아닙니다. π는 이미 학습한 수열을 얼마나 정확히 다시 생성하는지 재는 과제입니다.

ACT I에서는 동일 관측 조건의 전체망 자율 회상 우위를 확인하지 못했습니다.
ACT V의 다섯 교란 곡선과 세 후속 진단은 완료됐습니다. 그 뒤 추가 연구 후보를
[브리핑](additional-research-brief.md)하고, 관측 잡음 배분의 해독 개선이 자율 회상에도
이어지는지 첫 번째 확장을 실행했습니다. 다른 후보를 한꺼번에 실행하지 않았습니다.

Threshold 1 전체망은 회상 길이와 유지율의 사전 지정 개선 기준을 함께 통과했습니다.
새 잡음에서 회상 길이 차이는 두 기존 모델 집단에서 3.700/6.167자리,
유지율 차이는 10.986/16.283%p였습니다. 전체망과 부분망의 우위 비교가 아니라
같은 모델에서 두 잡음 배분을 비교한 결과입니다. 새 모델 학습은 없습니다.
개선 뒤에도 평균 유지율은 약 45.55% / 50.76%이고, 가장 강한 잡음에서는
회상이 약 1자리에 그쳤습니다. 안정적인 긴 회상의 복원은 아닙니다.

처음 틀리기 전까지는 모델이 낸 숫자가 정답이므로, 정답을 계속 주는 실험과
입력이 같습니다. 이 성질로 첫 오류 위치를 계산할 수 있지만, 틀린 뒤의 출력은
실제로 실행해야 알 수 있습니다. 이번에는 2016개 첫 오류 기록과 336개 실제
신경 궤적을 구분해 저장했습니다. 이 둘을 같은 수의 자율 실행으로 세지 않습니다.

## 모델 안에서 일어나는 일

ACT II의 네 가지 수열, 길이32–512, K=2·4·10·16, 과거 해독과 교차 수열
전이 진단과 현행 III-A/B/C/D 패널을 마쳤습니다. 전체 뇌 위치 규명이나
ACT IV의 생물학적 내부 학습 성공을 확인했다는 뜻은 아닙니다. 평균·크기 보정은 일부 도움이 됐지만
완전 회복에는 실패했습니다. 상태 차이의 방향과 출력층 증폭에 대한 두 가설도
지지되지 않았습니다. 이후 새 seed에서도 정렬의 부분 이득을 확인했습니다.
이후 KCγ 제거와 matched 대조, 서로 겹치지 않는 부분집합 대조까지 실행했습니다.
출력층을 고정하면 해독이 크게 떨어지고 재학습하면 정보를 다시 읽을 수 있음을
확인했고 새로운 입력 배치·수열 seed에서도 재현했습니다. 직접 입력만 끊고
연결을 남기는 대조28조건, 다른 KC 유형·DAN·APL·고연결 집단의 패널299조건도
실행했습니다. 이어 ACT III-B에서 DAN/약한/강한/최단경로 중심성이 높은/역할 집단 내부·사이
연결을 비교했고,정규화 가중치 대조까지 추가해 총286조건을 검증했습니다.
이어 ACT III-C에서 무작위 배선·연결 수 보존·역할 보존·가중치 섞기의
네 대조를 169조건으로 비교했습니다. 이어 다섯 경로의 민감도를273조건으로
비교하고 독립 검증했습니다. 관측 위치 진단130조건도 완료했습니다. 공통 지연1–5의 사후 분석과 새 A/B/C/D 비교117조건도 마쳤습니다.
그 보상·국소 규칙39조건도 실행했으나 사전 성공 기준은 실패했습니다.
그 방향 진단과 잡음 일치 비교도 완료했습니다.
같은 학습 궤적의 고정 시점별 갱신 방향과 마지막 민감도 진단까지 마쳤습니다. 전체 뇌나 포함되지 않은 downstream 집단의
위치를 규명한 것은 아닙니다. 여기서 설명한 과거 입력 해독 진단의 점수는 자율 회상과 구분합니다.
지금 결과는 KCγ가 실제 동물의 기억에 불필요하다는 뜻이 아닙니다.

숫자를 특정 입력 뉴런에 신호로 넣습니다. 신호가 연결망을 따라 퍼지며 이전
입력의 흔적과 섞입니다. 출력층은 일부 뉴런의 상태를 보고 다음 숫자를 고릅니다.
기존 회상 기준 모델에서는 연결망 내부를 고정하고 **출력층만 학습**합니다.
새 A단계 대조는 인공 교사로 일부 내부 연결도 바꾸지만, 실제 생물학적 학습 성공으로
해석하지 않습니다. 관측 직전 연결이 내부 출력층처럼 학습됐을 가능성도 있습니다.

반드시 세 가지를 나눠 봅니다. 과거 입력의 흔적이 상태에 남는 것은
**표현(representation)**, 그 흔적을 읽어 답을 고르는 것은 **해독(decoding)**,
경험에 따라 내부 연결 자체가 바뀌는 것은 **학습(learning)**입니다.
인공 교사의 연결 변화와 생물학적 동기 규칙에 의한 기억 형성을 구분합니다.
후자는 아직 성공했다고 주장하지 않습니다.

## 용어를 직관적으로 이해하기

| 용어 | 뜻과 주의점 |
|---|---|
| Connectome(연결 지도) | 어떤 뉴런이 어떤 뉴런에 연결되는지를 나타낸 지도입니다. 연결 지도만으로 살아 있는 뇌의 모든 성질을 재현하지는 못합니다. |
| Reservoir computing(고정 연결망 계산) | 입력이 퍼지고 남기는 상태 변화를 이용하고, 주로 출력층을 학습하는 방식입니다. |
| Readout(출력층) | 관측 뉴런의 상태를 답으로 바꾸는 해독기입니다. π 자율 회상 기준 모델은 48→8→10의 작은 비선형 출력층이고, 최근 K4 과거 해독 진단은 48→4의 선형 출력층을 지연별로 사용합니다. |
| Teacher forcing(정답 입력) | 매 단계 실제 앞 숫자를 공급해 다음 숫자를 맞히게 합니다. 이전에 틀렸어도 다음 입력은 정답이므로 자율 회상보다 쉬울 수 있습니다. |
| Autonomous recall(자율 회상) | 처음 세 숫자만 준 뒤 모델이 낸 답을 다음 입력으로 다시 넣습니다. 오류가 이어질 수 있습니다. |
| Pi Memory Score | 제공된 prompt를 제외하고 첫 오류가 나기 전까지 연속으로 맞힌 숫자 수입니다. 평가 한도를 다 맞히면 그보다 오래 기억하는지는 모릅니다. |
| LIF neuron(누설 적분 발화 뉴런) | 입력을 누적하되 시간이 지나며 누적값이 새고, 문턱을 넘으면 발화하는 단순 모델입니다. 생물학적 뉴런 자체가 아닙니다. |
| Dopamine-gated plasticity(도파민 신호로 조절하는 연결 변화) | 특정 활동과 조절 신호가 함께 있을 때 연결 크기를 바꾸는 규칙입니다. 구현 작동과 실제 기억 개선은 별개입니다. |
| Ablation(제거 실험) | 뉴런이나 연결 일부를 제거하고 성능 변화를 봅니다. 기존 출력층 고정과 제거 후 출력층 재학습은 다른 질문입니다. |
| Shuffled control(섞은 대조망) | 연결이나 가중치를 섞어 원래 구조의 어떤 성질이 중요한지 비교합니다. 무엇을 보존했는지 밝혀야 합니다. |
| Degree-preserving control(연결 개수 보존 대조망) | 뉴런별 들어오고 나가는 연결 수를 유지하면서 연결 상대를 바꿉니다. 역할이나 가중치까지 보존하는지는 별도로 확인합니다. |
| Memory capacity(기억 용량) | 반드시 측정 정의가 필요합니다. 연속 정답 수, 과거 무작위 입력 복원 능력, 정보 이론적 용량은 서로 다릅니다. L×log2(K)는 정확한 접두사 회상 점수의 비트 환산이며 Shannon 용량이 아닙니다. |

## 결과를 읽을 때

학습 정확도가 높아도 첫 오류가 일찍 날 수 있습니다. 처음 32개 답에 학습 비중을
더 주면 초반 회상은 늘지만 뒤쪽 정확도가 떨어질 수 있습니다.
π를 학습하고 같은 구간을 재생하는 것은 보지 않은 π 숫자를 발견한 것이 아닙니다.
π 숫자가 수학적으로 무작위라고 가정하지 않으며, 무작위 수열은 별도 대조군입니다.

ACT II의 작은 비교는 π, prompt 뒤를 무작위로 만든 숫자열, 숫자 빈도를 보존해
순서만 섞은 π, 짧은 패턴을 반복한 주기 수열을 사용합니다. 모두 처음에는 정답
수열로 따로 학습하고, 평가 때는 앞의 세 숫자만 줍니다.
함께 사용하는 **1차 전이 대조 모델**은 직전 숫자 하나만 보고, 학습 중 가장 자주
뒤따랐던 숫자를 냅니다. 이 모델도 주기 수열을 완주한다면 높은 점수를 복잡한
장기 기억의 증거로 해석해서는 안 됩니다.

**정확한 접두사 회상 점수**는 첫 오류 전까지 맞힌 기호 수입니다. π일 때만
Pi Memory Score라고 부릅니다. 이를 기호당 log2(K) 비트로 환산해도 수열의
압축 가능성은 반영하지 않습니다. 단순 반복 수열에서 큰 비트 점수가 나와도
그만큼의 독립적인 정보를 저장했다는 뜻은 아닙니다.

전체 연결망을 실행했다는 사실은 전체 뇌의 생리학을 재현했다는 뜻이 아닙니다.
실패한 가소성·강건성 결과도 보존합니다. 여러 seed는 여러 계산 초기화이며
서로 다른 초파리 개체를 뜻하지 않습니다.

## 수열이 길어지면 무엇을 비교하나요?

길이32–512의 [실제 비교 결과](length-scaling-results.md)는100회 실행과 재현을
마쳤습니다. 두 모델 모두 길이32를 완주했지만, 길이512의 평균 연속 회상은
부분망14.6·전체망9.5였습니다. 아래의 학습 절차와 평가 한도를 함께 해석해야 합니다.

길이 scaling은 같은 무작위 수열을 짧게 잘라 학습한 경우와 길게 학습한 경우를
비교합니다. 처음 세 기호는 알려 주므로 길이32의 평가 한도는29개입니다.
29개를 전부 맞혔다면 그보다 얼마나 더 기억할 수 있는지는 알 수 없습니다.
따라서 연속 정답 수, 평가 길이 대비 비율, 완주 비율을 함께 봅니다.

같은 앞부분을 입력하면 학습 전 연결망의 상태도 같아야 합니다. 다만 더 긴
수열로 출력층을 학습하면 정규화와 학습된 출력층이 달라집니다. 긴 과제에서
앞부분을 틀렸다고 해서 연결망 상태의 정보가 저절로 사라졌다고 단정할 수는
없습니다. 처음32개에 같은 가중치를 주더라도 전체 학습 자료가 늘면 그 부분의
상대적 비중은 줄어듭니다. 이 실험은 그러한 학습 절차를 포함한 결과이며,
연결망 고유의 저장 용량을 직접 측정한 것은 아닙니다.

## 초반을 더 강조하면 기억이 늘어난 건가요?

길이512의 [후속 실험](prefix-mass-results.md)은 입력 수열과 학습 전 신경 상태를
그대로 두고, 출력층이 처음32개 정답을 학습하는 비중만 높였습니다. 새 seed로
확인했을 때 평균 연속 회상은 부분망10.83→33.00, 전체망11.17→23.33으로 늘었습니다.
그러나 뒤쪽477개 정답에 대한 **정답 입력 정확도**는 각각5.21·3.46%p 낮아져,
실험 전에 정한 허용 손실2%p를 넘었습니다. 전체망의 개별 조건에는7→0으로
악화된 경우도 있습니다. 평균 이득이 모든 조건의 성공을 뜻하지 않습니다.

이는 같은 상태에서 무엇을 우선 읽어내도록 출력층을 가르치는지가 중요하다는
결과입니다. 연결망 안의 정보가 늘거나 내부 연결이 학습했다는 증거는 아닙니다.
그 후 별도의 무작위 입력에서 과거 기호를 읽는 [비교](delayed-symbol-results.md)도
완료했습니다. 평균 과거 지연 정답률은 부분망60.42%·전체망51.10%였습니다.
특정 수열을 출력층이 외운 효과와 과거 입력의 흔적을 구별하는 진단이며,
전체망 우위 기준은 통과하지 못했습니다. 그 뒤 길이128에서 기호 종류 수를
2·4·10·16으로 바꾸는 ACT II-A 비교도 완료했습니다.

## 과거 입력을 읽는 실험은 무엇이 다른가요?

서로 다른 무작위 수열 두 개를 준비합니다. 하나로 출력층을 학습하고, 다른
수열을 연결망에 입력하며 현재 상태에서 몇 단계 전 기호를 맞히게 합니다.
예를 들어 지연3은 지금 상태로 세 단계 전 입력을 고르는 것입니다. 지연0은
지금 입력을 읽는 능력이므로 과거 기억과 나눠 봅니다.

이번 출력층은 관측 뉴런 값을 가중해 더하는 선형 방식입니다. 학습 때 정답과
상태의 시간 대응을 일부러 어긋나게 한 출력층도 비교합니다. 이 대조보다 잘
맞히는지는 유용한 검사지만, 실제 생물학적 배선만의 장점인지는 별도 구조 대조가
필요합니다. 이 출력층이 못 읽는다고 모든 정보가 없다고 단정할 수도 없습니다.

## 기호 종류가 많으면 반드시 더 어려운가요?

이번 [K 비교](alphabet-memory-results.md)에서는 그렇지 않았습니다. K2→K16의
평균 연속 회상은 부분망25.0→103.1, 전체망27.3→88.0으로 늘었습니다. 모든 K에서
제한적인 학습 수열 회상 기준은 통과했지만 전체망 우위 기준은 통과하지 못했습니다.

[후속 문맥 분석](context-memory-results.md)은 이 설명 후보를 검사했습니다.
**n-gram 예측기**는 앞의 몇 기호 조합 뒤에 어떤 답이 자주 나왔는지 표에 저장합니다.
예를 들어 같은 `010` 뒤에2도3도 나왔다면, 이 세 기호만 보고는 두 위치를
구별할 수 없습니다. 이런 경우를 **문맥 충돌**이라고 부릅니다.

기존20개 수열에서 문맥 길이1·2·3·4·5·8을 모두 비교했습니다. K2→K16에서
2기호 문맥의 최소 분류 오류는22.72%p 줄고, 3기호 문맥 모델의 평균 회상은
1.8→60.8기호로 늘어 사전 기준을 통과했습니다. 5기호 문맥 모델은 K10·K16의
모든 수열을125기호까지 완주했습니다. 이 표에는 connectome이 들어 있지 않습니다.

다만 모든 차수가 좋아진 것은 아닙니다. 1기호 모델은 여전히 약했고, 긴 문맥이
겹치지 않아도 처음 주어진 세 기호가 모호하면 첫 답부터 틀리는 사례가 있었습니다.
신경망 내부의 원인을 확인한 결과도 아닙니다. K에 따라 자극 뉴런의 합집합과
출력층 크기가 변하므로, 후속 [고정K 문맥 개입](context-intervention-results.md)도 완료했습니다.
기호 종류4개·길이128·각 기호32회와 prompt를 맞춰40회를 비교했습니다.
부분망은 본 실험에서 평균12.3기호 개선했지만 새 seed에서는7.0기호·3개 중2개
개선으로 확인 기준을 통과하지 못했습니다. 확인된 모델은 없습니다. 순서를 바꾸면 전이
빈도와 초반 충돌 위치도 함께 변하므로 문맥 충돌 하나의 인과 효과로 단정하지
않습니다. 이후 저장 상태 해독과 교차 수열 전이 진단도 아래와 같이 완료했습니다.

## 과거를 읽을 수 있는데 왜 다음 답은 틀리나요?

[첫 진단](frozen-state-probe-results.md)은 관측된48개 뉴런 상태에서 과거 기호와
다음 기호를 각각 읽었습니다. 과거 기호는 두 연결망과 두 수열 조건 모두에서
대조군보다 잘 읽혔지만, 낮은 충돌 조건의 다음 기호 개선은 사전 기준을 통과하지
못했습니다. 지난 입력을 보존하는 능력과 임의의 수열을 이어 만드는 능력은 다릅니다.

검증이 끝난 뒤 [두 번째 진단](cross-arm-probe-results.md)도 실행했습니다.
한 수열에서 학습한 출력층을 그대로 두고 반대 조건의 수열 상태를 읽게 했습니다.
과거 기호 해독은 유지 기준을 통과했습니다. 첫 seed 집단에서 평균 손실은
부분망0.97%p·전체망0.83%p였고,4/5 seed에서는 작은 감소가 있었습니다.
따라서 변화가 전혀 없었다거나 새 수열 전체를 외웠다고 말하지 않습니다.

두 수열은 같은 조상 수열에서 만들어졌고 같은 위치의 기호도 약60%가 같습니다.
기호가 바뀐 위치도 따로 검사했지만 임의의 독립 수열로 일반화했다고 단정할 수
없습니다. 이후 **독립 K=4 입력의 실제 부분망·재배선망 구조 대조**도
완료했습니다. 두 조건 모두 과거 입력을 해독했지만 실제 배선의 우위는
확인되지 않았습니다. [앞선 구조 대조 결과](structural-k4-results.md)에서 seed별 결과와
보존된 연결 속성, 정규화의 한계를 설명합니다.
