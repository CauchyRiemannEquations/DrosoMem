# ACT V — 모델 가정과 생물학적 타당성의 범위

이 문서는 실행 코드와 고정 설계의 가정을 확인하는 감사다. 새로운 생리학적
자료나 생체 실험으로 모델을 검증한 문서가 아니다. ACT V의 실험 결과와 별도로 읽는다.

| 항목 | 실제 구현 | 이 구현만으로 확인하지 못하는 것 |
| --- | --- | --- |
| 연결 구조 | 고정한 FlyWire v783 원자료의 부분/전체 그래프, threshold5/1 | 다른 개체·발달 단계·가변적인 기능적 연결에서도 같은 결과인지 |
| 뉴런 상태 | 연속 값, tanh, 공통 leak=.6 | 실제 발화율이나 spike train 자체인지; 세포별 생리 파라미터 |
| 계산 시간 | 한 symbol에 한 단계; MBON만 새 KC 상태를 읽는 지정 순서 | 한 step의 생물학적 시간, 실제 전달 지연 |
| 연결 세기 | 각 뉴런의 incoming absolute-weight sum을 gain=.9로 정규화 | 접촉 수에서 실제 시냅스 효능으로의 정량적 변환 |
| 입력 | 숫자마다 고정한 KC 집합을 직접 자극; 전체망에도 같은 root IDs | 실제 감각 입력 경로나 숫자라는 자극의 생물학적 표현 |
| 관측/학습 | 48 MBON을 읽는 외부 482-parameter head; clean에서만 학습 | 초파리 내부의 실제 학습 규칙이나 출력 신경 회로 |
| 상태 잡음 | 뉴런·시간별 독립 Gaussian; 모델 상태에 더하고[-1,1]clip | 실제 잡음의 세기·상관·역할별 분포; 측정한 막전위 잡음 |
| 연결 제거 | CSR의 연결 하나를 Bernoulli 방식으로 제거; 생존 연결 재정규화 없음 | 개별 접촉 하나의 손실과 같은 사건인지; 구조적 보상/회복 |
| 뉴런 제거 | 입력·관측 포함 모든 역할이 후보; 상태를 지속0으로 고정 | 저장된 기억만의 손상인지; 감각/해독 접근 손상과의 분리 |
| 가중치 교란 | 부호와 연결 유무를 보존하는 lognormal 배수 | 실제 시냅스 변화 분포 및 장기 homeostasis |
| 전체망 비교 | 같은 관측·입력 예산과 같은 뉴런/연결당 교란 draw | 같은 총 교란 에너지; 순수 network scale만의 효과 |
| 적응 | 교란 후 head·전처리·연결 보상 학습 없음 | 경험 이후 기능이 회복되는지 |

특히 negative tanh 상태를 음의 생물학적 발화율로 읽지 않는다. 여기서 active
neuron은 |state|>1e-8인 좌표 수이며, spike가 관측된 뉴런 수가 아니다.
구조는 실제 connectome 자료를 사용하지만 상태 변수와 학습 절차에는 계산적
선택이 포함된다. 과거의 별도 LIF/도파민 연구가 이번 rate 모델을 생리학적으로
검증해 주는 것도 아니다.

생리학적 파라미터·잡음 보정, 다른 동역학, 상관 잡음과 적응 학습은 별도 가설과
자료가 필요한 확장으로 남긴다. 실패한 강건성 기준을 이런 확장의 성공으로
바꾸어 표기하지 않는다.
