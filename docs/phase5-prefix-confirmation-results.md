# 구간별 확인: 초반 회상 이득과 후반 정확도 손실 모두 재현

**32자리·4배 가중 규칙을 바꾸지 않고 새 시드와 다른 π 구간에서도 연속 회상 개선을 확인했다. 실제 연결의 평균은 약 6자리에서 34자리로 늘었다. 그러나 후반 정확도는 떨어졌으며, 섞은 연결에서도 비슷한 효과가 나타났다. 확인된 성과는 고정 상태를 읽는 출력층의 접두사 우선 학습 효과다.**

## 무엇을 확인했나

이전 실험에서 실제 연결 회상은 9.93→32.43자리였다. 이번에는 같은 규칙이 시작 숫자열이나 기존 seed에만 유리했는지 확인했다. 시작 인덱스 0, 1000, 2000에서 각각 200자리 구간을 취했고 새로운 seed 1142–1144를 썼다. 인덱스 0은 정수부 3이고 소수점은 제외한다.

각 구간마다 reservoir를 0으로 초기화하고 출력층을 처음부터 별도로 학습했다. prompt도 각 구간의 첫 세 숫자다. 따라서 **다른 구간에서의 재현은 미학습 π를 즉석에서 예측한 결과가 아니다.** 구간 앞의 숫자·상태를 물려받지 않는다.

두 686뉴런 부분망 × 세 seed × 실제/role-degree-shuffled × 세 구간으로 36개 신경 상태 조건을 만들었다. 조건마다 세 출력층 초기화와 균등/초반 가중 학습을 비교해 총 **216개 모델**을 학습했다. incoming-L1, mbon_after_kc, 48 MBON 관측, 482개 학습 파라미터, 2,000 Adam 업데이트, 학습률 .03, L2=1e-5는 유지했다. 가중 구간은 처음 생성할 32개 target, 비중은 4배이며 가중치 합으로 정규화했다. 연결·입력은 학습하지 않았다.

## 실제 연결 결과

회상은 제공한 세 숫자를 제외한 **첫 오류까지의 연속 정답 수**, 평가 한도는 197이다.

| 구간 시작 인덱스 | 균등 학습 회상 | 초반 가중 회상 | 조건 평균 승/무/패 | 세 초기화 모두 개선한 조건 |
|---|---:|---:|---:|---:|
| 0 (새 seed 반복) | 6.44 | 34.33 | 6 / 0 / 0 | 6 / 6 |
| 1000 (주 확인) | 6.28 | 34.50 | 6 / 0 / 0 | 6 / 6 |
| 2000 (주 확인) | 6.11 | 33.94 | 6 / 0 / 0 | 5 / 6 |

사전에 고정한 확인 기준은 새 구간 각각에서 평균 회상 차이 양수, 조건 평균 개선 4/6 이상, 모든 초기화 개선 4/6 이상이었다. **새 구간 두 곳 모두 충족했다.** 이 기준은 기술적 재현 판정이며 통계적 유의성 기준이 아니다.

개별 실제 모델 비교에서는 54쌍 중 53개가 개선되고 1개가 악화했다. 초반 32자리 완주는 0/54→50/54였다. 가중 모델의 최소 회상은 구간별 4, 30, 11자리로 실패가 남아 있다. 197자리 전체 완주는 없었다. 최고점을 대표 기억 용량으로 주장하지 않는다.

## 대가: 후반 정확도 하락

| 실제 연결 구간 | 초반 32자리 정확도 (균등→가중) | 이후 165자리 정확도 (균등→가중) |
|---|---:|---:|
| 0 | 88.02% → 99.48% | 88.11% → 79.56% |
| 1000 | 81.60% → 99.83% | 82.15% → 74.92% |
| 2000 | 86.63% → 99.83% | 84.34% → 76.43% |

세 구간을 같은 비중으로 기술하면 실제 연결 회상은 6.28→34.26자리, 후반 정확도는 84.87%→76.97%, 전체 학습 target 정확도는 84.95%→80.56%였다. 즉 **초반 회상에 유리하게 오류 위치를 이동한 결과**가 반복됐다. 전체 평균 적합이나 저장 정보량이 증가했다고 해석하지 않는다.

## 연결을 섞어도 나타나는 효과

| 섞은 연결 구간 | 균등 회상 | 가중 회상 | 조건 평균 승/무/패 |
|---|---:|---:|---:|
| 0 | 10.78 | 36.50 | 6 / 0 / 0 |
| 1000 | 12.50 | 33.61 | 6 / 0 / 0 |
| 2000 | 15.67 | 37.28 | 6 / 0 / 0 |

섞은 연결도 후반 정확도가 각 구간에서 하락했다. 효과가 실제 해부학적 배선에 고유하다는 근거가 아니다. 구간 1000에서 실제 가중 회상이 조금 높다는 단일 셀을 전체 우위로 선택하지 않는다.

세 구간은 같은 그래프·입력·초기화 seed를 반복해서 사용한다. 이들을 독립적인 그래프 표본으로 세지 않는다. 두 부분망도 한 개체에서 왔고 서로 겹친다. 구간별 여섯 조건은 두 부분망 × 세 계산 seed이지 여섯 초파리 개체가 아니다.

## 검증과 재개 기능

- 전체 **71 tests 통과**. 구간 인덱스, 상태 초기화, 중단→재개 동등성, 설정/코드 변경 거부, checkpoint 손상/누락 거부를 추가했다.
- **36개 상태 재구축, 216개 출력층의 모든 회상 문자열 정확히 재생**. 위치별 교사입력 예측, 학습 지표, 집계, frozen 연결, source/data/protocol/file hash를 검증했다.
- 첫 실제 부분망·첫 seed에서 구간별 여섯 모델, 총 **18개를 독립 재학습**하여 파라미터 해시까지 일치했다. 나머지는 저장 모델 재생이며 전체 독립 재학습을 주장하지 않는다.
- 사용한 π 2,200자리 모두 mpmath와 Decimal 계산이 일치했다.
- 실제 실행도 첫 조건 6개 모델을 저장하고 종료한 뒤 `--resume`했다. manifest의 재사용 1개/새 학습 35개 조건 기록으로 확인할 수 있다. 재개 후 본계산 약 119초이며 첫 조건 약 4초는 이 시간에 포함되지 않는다. 하드웨어에 따라 달라진다.
- 조건별 NPZ에는 모든 head, 위치별 예측, 생성 문자열, 학습 곡선이 들어 있다. ledger에 기록된 파일은 SHA256 검사를 통과해야 재사용한다. ledger 없는 파일은 미완료로 보고 다시 계산한다. 같은 출력 폴더는 한 프로세스만 사용한다.
- pytest/mpmath는 이번 세션에서 다시 설치했다. 이 제약은 해결됐으며 테스트를 건너뛰지 않았다.

## 현재 판단과 다음 한 가지

**초반 32자리를 우선하는 출력층 학습이 회상 길이를 늘리는 현상은 이제 다른 두 구간에서도 재현됐다.** 현재 34자리 부근의 결과는 32자리 가중 창 직후에 오류가 나타나는 패턴과 맞는다. 이것이 신경망의 고유한 34자리 용량 한계라는 뜻은 아니다.

다음 실험은 전체 뇌 확장보다 **누적 학습 범위를 32→64→128자리로 늘리는 curriculum**이 타당하다. 6,000회라는 같은 총 업데이트 예산 안에서 (a) 균등 6,000회, (b) 고정 32자리/4배 6,000회, (c) 각 2,000회씩 32·64·128자리/4배를 비교하는 설계를 제안한다. 시드·평가 구간·성공 기준은 실행 전에 다시 고정해야 한다. 먼저 배운 초반이 유지되는지와 64/128자리 연속 회상 여부를 함께 보고, 마지막 모델만 주 평가로 삼는다. 이것은 **제안이며 이번에는 구현·실행하지 않았다.**

## 실행

```bash
python -m pip install -e ".[test]"
python -m pytest -q
python -m flying.training.phase5_prefix_confirmation --output outputs/confirmation_reproduce
# 중단된 경우에만 이어 실행
python -m flying.training.phase5_prefix_confirmation --output outputs/confirmation_reproduce --resume
python -m flying.training.phase5_prefix_confirmation --output outputs/confirmation_reproduce --verify
```

새 출력 폴더를 사용한다. config/code/data/protocol/패키지가 바뀌면 resume을 거부한다. verifier의 source hash를 맞추려면 이 실험을 만든 커밋에서 실행하며, 향후 코드 변경 후에도 과거 데이터를 덮어쓰지 않는다.
