# ACT V 이후 추가 연구 브리핑 — 2026-09-30

[ACT V](act5-final-results.md)의 지정 연구는 완료했다. 전체망의 자율 회상 우위와
강건성은 확인되지 않았지만, 관측 잡음의 배분을 바꾸면 정답 입력 해독이 개선됐다.
아래는 해결하지 못한 질문의 우선순위이며, 여러 실험을 동시에 시작하는 계획이 아니다.

| 순서 | 질문 | 정보가치 | 현재 상태 |
| --- | --- | --- | --- |
| 1 | 해독 개선이 자기 출력 피드백의 자율 회상에도 이어지는가? | 현재 양성 결과와 실제 순서 회상을 직접 연결; 오류 이후 feedback 손실을 구분 | [실행·검증 완료](feedback-noise-results.md) |
| 2 | 같은 효과가 무작위 숫자와 섞은 π에도 유지되는가? | π에 특화된 효과와 보다 일반적인 해독 민감도를 구분 | 제안, 미등록·미실행 |
| 3 | 같은 대조에서 실제 배선과 degree/role 보존 대조가 다른가? | 일반적인 feature-scale/head 성질과 특정 topology의 기여를 구분 | 제안, 미등록·미실행 |
| 4 | 뉴런 집단별·상관 잡음과 측정 기반 동역학에서도 유지되는가? | 현재 독립 잡음·공통 rate dynamics 가정의 외적 타당성을 검사 | 별도 생리 자료·범위 설정 필요, 미실행 |

이번 범위는 1번만이며 실행·검증을 완료했다. [실험 protocol](feedback-noise-protocol.md)을 결과 전에
고정했다. 모델·head·관측 예산·수열은 그대로 두고 새 잡음 3개를 사용했다.
기존 두 모델 집단을 재사용하므로 새 모델 holdout이나 생물학적 반복으로 표현하지 않는다.
결과가 부정적이어도 강도·학습·seed를 바꾸어 성공을 찾지 않는다.

## 재계산을 줄일 수 있는 정확한 관계

결정론적 연결망과 고정 head에서 같은 prompt·시점별 관측 잡음을 사용하면,
자율 출력이 처음 틀리기 전까지 입력은 정답 입력과 같다. 귀납적으로 상태와
관측도 같으므로 **첫 오류 위치는 정답 입력 궤적에서 계산할 수 있다**.
이것은 전체 정답 입력 정확도를 자율 회상 정확도로 바꾸는 주장이 아니다.
첫 오류 이후에는 입력과 상태가 달라지므로 실제 자율 실행이 필요하다.

기존 ACT I도 [clean first-error equality](../src/flying/training/whole_brain_memory.py)를
검사한다. 이번에는 관측 잡음을 포함해 이 관계를 검증한다. 저장된 기존 기록의
첫 오류 재분석은 retrospective로 구분하고, 새 잡음의 prefix 계산과 실제
자율 rollout은 prospective로 구분한다. 모든 새 잡음의 prefix를 계산하되,
첫 새 잡음에서는 모든 모델·강도·배분의 실제 197자리 출력을 저장한다.

이 연구는 완료된 ACT V를 미완료로 바꾸지 않는 별도 확장이다. 생물학적 내부
학습은 수행하지 않으며 결과에 따라 새로운 실험을 자동 추가하지 않는다.

최종 결과와 수치 검증은 [자율 회상 보고서](feedback-noise-results.md)를 따른다. 다른 세 후보는 실행하지 않았다.
