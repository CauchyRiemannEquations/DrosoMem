# Constrained BPTT positive-control protocol

This is a small computational positive control before whole-brain scaling. Can a next-digit objective with exact recurrent derivatives produce useful learned changes under the existing KC→MBON mask, sign and incoming-strength constraints?

The two pinned 686-neuron circuits, KC-only input, MBON-only affine readout, one leaky-tanh update per digit and 200-digit π training prefix are retained. Two normalizations, real/role-degree-shuffled graphs, fresh seeds 742–744, four conditions and two readout views yield **96 network conditions, 72 optimization runs and 192 evaluations**. No new anatomical data or whole-brain model is introduced.

Conditions: frozen; full sequence BPTT with correct next-digit labels; direct last-step derivative of the same objective (stop recurrent state gradients); full BPTT with once-permuted training labels. The permuted condition preserves label frequencies. Every graph/seed uses the same initial supervised 400-epoch softmax policy and feature statistics, held fixed through connection optimization. Evaluation uses that frozen policy as primary; a separately fitted correct-label readout is secondary and is explicitly additional supervised learning. This is not reward-only training or a local biological learning rule.

Weights outside existing KC→MBON edges cannot change. For a plastic edge j into row i, use q_j=softmax_row(log|w0_j|+theta_j) and |w_j|=epsilon|w0_j|+(1-epsilon)S_i q_j, with fixed source signs and row budget S_i. Epsilon=.0001. Theta starts at zero (exact original matrix), is bounded to [−2,2], and is trained by Adam for 100 full-sequence epochs at .01 with global gradient norm cap 5. No readout or encoder weights are optimized at this stage. Incoming-L1 contraction bounds remain conserved; the initial spectral radius is not maintained during learning.

Full BPTT differentiates through all 199 teacher-forced inputs and the fixed policy; no truncation or stochastic reward surrogate is used. The local-gradient condition has the same forward objective, parameterization and optimizer but omits previous-state derivatives. Finite-difference tests include a network with feedback and test both zero and nonzero edge logits. Optimization is a heuristic under nonconvex constraints even with an exact gradient; failure is not a proof of representational impossibility.

Checkpoint selection minimizes that condition's training cross entropy, including epoch zero. Never select by autonomous recall, unseen π labels, a winning seed, or an alternative learning rate. The permuted model selects on its own permuted objective, and is later evaluated against correct labels. All states and train-only statistics are reset/refitted according to the existing pipeline; evaluation freezes weights/readout and generates from `314` without target access.

Primary outcome: paired difference in consecutive correct generated digits before the first error. Secondary: true teacher-forced cross entropy/accuracy and objective convergence. Correct-label full BPTT must be compared to frozen and permuted controls before calling a learning gain. Compare full/local to assess whether full temporal derivatives matter; compare real/shuffled to assess anatomical specificity. No automatic claim of unseen π prediction, independent biological replication or biological dopamine learning is allowed.

This is one prespecified small experiment, not a sweep. If it improves recall, report every seed and the corresponding controls; a later independent confirmation is required before treating a selected advantage as robust. If it only reduces teacher-forced loss, explicitly distinguish that from autonomous sequence memory. If all learners fail, consider optimization/parameterization/observation constraints without claiming that real flies cannot learn.
